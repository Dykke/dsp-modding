# DSP Mods

Source repository for a small set of **Dyson Sphere Program** mods built
on **BepInEx 5**. Each mod is a self-contained folder; the published
release ZIPs are the consumer-facing artifact.

---

## Installation (for players)

1. Install [BepInEx 5 for DSP](https://thunderstore.io/c/dyson-sphere-program/p/xiaoye97/BepInEx/).
2. Download the mod you want from its release page.
3. Extract the ZIP into your `Dyson Sphere Program` folder. The ZIP is
   laid out so files land in the right places (`BepInEx\plugins\`,
   `BepInEx\config\`, etc.).
4. Launch the game. The mod loads automatically and writes its default
   config to `BepInEx\config\` on first run.

## Requirements

- Dyson Sphere Program (latest stable)
- BepInEx 5 (5.4.17 or newer)
- A mod folder to exist; you are reading this before the first one has
  been added.

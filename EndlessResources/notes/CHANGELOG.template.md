## How to use this template
- Place at `<ModFolder>\CHANGELOG.md` (root of the mod folder).
- Delete this `BEGIN:TEMPLATE_USAGE` block.
- One `## [X.Y.Z] - YYYY-MM-DD` heading per release, newest on top.
- Inside each release, use the subsection order: `Added`, `Changed`,
  `Deprecated`, `Removed`, `Fixed`, `Security`.
- Only list sections that have entries. Delete empty ones.
- Link the version heading to the GitHub release tag if the repo has tags.

## How to use this template
- This is the **player-facing** notes for a single release. Different from
  `CHANGELOG.md` (which lists every change) and `README.md` (which is
  always-current docs).
- One file per release: `RELEASE_NOTES.md` in the mod folder, or
  `releases\v1.2.3.md`. Bump the file each time.
- Delete this `BEGIN:TEMPLATE_USAGE` block.
- Keep it short. Screenshots, one-paragraph "what's new", and a short
  upgrade-notes section.
